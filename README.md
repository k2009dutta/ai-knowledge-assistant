# AI Knowledge Assistant

A production-oriented AI Knowledge Assistant built using Python, FastAPI,
Amazon Bedrock, RAG, vector search, and AWS cloud-native technologies.

## Day 1

Implemented:

- FastAPI application
- Health endpoint
- `/ask` API
- Pydantic request validation
- Pydantic response model
- Swagger API documentation

## Current Architecture

User → FastAPI → Python API

## Future Architecture

User → FastAPI → RAG → Vector Database → Amazon Bedrock → Answer
